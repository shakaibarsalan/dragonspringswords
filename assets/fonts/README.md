# Fonts

Shippori Mincho (headings) and Zen Kaku Gothic New (text), downloaded from Google Fonts.
Only the Latin and Latin Extended parts are kept, so pages load fast. Both fonts are under the
SIL Open Font License 1.1 (https://openfontlicense.org), which allows using them on a website.

Cinzel (the "Dragon Spring" wordmark, the same face as the 3D logo) comes from the Blender logo
project (logo-options/blender/fonts/Cinzel.ttf), cut down to Latin as cinzel-var-latin.woff2
(weights 400 to 900). Also SIL Open Font License 1.1.
